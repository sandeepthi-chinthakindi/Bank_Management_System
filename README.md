# Banking Management System

## Project Description
Banking Management System is a web-based application developed to manage basic banking operations. The system allows users to register, log in securely, view their account balance, make deposits and withdrawals, and view their transaction history.

## Features
- User Registration
- User Login and Logout
- Account Balance Display
- Deposit Amount
- Withdraw Amount
- Transaction History
- User-specific Transactions
- MySQL Database Integration

## Technologies Used
- HTML
- CSS
- JavaScript
- PHP
- MySQL
- XAMPP

## Database
The project uses MySQL database through phpMyAdmin. The database contains tables for:
- Users
- Deposits
- Transactions

## How to Run the Project

1. Install XAMPP.
2. Start **Apache** and **MySQL** from XAMPP Control Panel.
3. Copy the project folder into:
   `C:\xampp\htdocs\`
4. Open phpMyAdmin:
   `http://localhost/phpmyadmin`
5. Create/import the `banking_system` database using the provided `sql_structure.sql` file.
6. Open the project in your browser:
   `http://localhost/BMS%20chatgpt/home.html`

## Project Structure

- `home.html` – Home page
- `register.php` – User registration
- `login.php` – User login
- `dashboard.php` – User dashboard
- `transaction.php` – Transaction processing
- `transactions.php` – Transaction history
- `deposits.html` – Deposit page
- `credits.html` – Credit page
- `logout.php` – Logout
- `db.php` – Database connection
- `sql_structure.sql` – Database structure
